# ⚡ Mega Elektrik – Corporate Website

**Modern, responsive and bilingual corporate website for Mega Elektrik.**

A redesigned corporate website presenting Mega Elektrik's electrical installation, maintenance, repair, engineering and contracting services.

## 🌐 Website Features

- 🇹🇷 Turkish / 🇬🇧 English language support
- 📱 Fully responsive design (mobile, tablet and desktop)
- ⚡ Modern corporate design and animations
- 🛠️ Service and solutions showcase
- 🏢 Corporate introduction and company experience
- 📂 Project and reference gallery
- 📍 Service areas and Google Maps integration
- 💬 WhatsApp service request form
- ☎️ Direct phone call buttons
- 🔍 SEO-friendly metadata
- 📲 Floating WhatsApp and call buttons

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Google Maps Embed
- Unsplash Images
- WhatsApp Click-to-Chat

## 📁 Project Structure

```text
/
├── index.html
└── README.md
```

The website is built as a single HTML file. CSS and JavaScript are embedded directly into `index.html`.

## 🚀 Deployment

This project can be hosted using GitHub Pages.

1. Upload `index.html` and `README.md` to the repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save your settings.

Your website will be published through GitHub Pages.
